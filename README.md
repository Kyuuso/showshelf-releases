## Comentarios / Feedback

¿Algo no funciona o tienes una idea? [Abre un issue](../../issues/new/choose). ShowShelf también lo abre por ti desde el enlace «Comentarios» de la ventana y de la web, o con `showshelf-cli feedback`: el formulario viene con la versión y el sistema ya puestos; no se envía nada hasta que lo publicas tú.

Something broken, or an idea? [Open an issue](../../issues/new/choose). ShowShelf can also open it for you from the "Feedback" link in the window and the web page, or with `showshelf-cli feedback`: the form comes with the version and system filled in, and nothing is sent until you post it yourself.
